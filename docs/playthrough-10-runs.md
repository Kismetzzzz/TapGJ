## 试玩方式说明

- **目标贪心**：严格按关卡目标进度选最优动作。
- **相克优先**：额外偏好相克消灭，并允许很小的短期分数回撤。
- **保守省牌**：减少召唤与秘术牌消耗，只接受明显有利的动作。
- **召唤铺路**：额外奖励空格召唤，用召唤调整棋盘与配对。
- **相遇反应优先**：偏好打在元素上触发反应，而非只看静态目标分。
- **复合循环优先**：明显偏好融合、分解，推动复合元素循环。
- **瓶子产牌优先**：优先增加元素瓶进度与瓶子产牌。
- **均衡目标优先**：额外关注均衡目标的差距与达成状态。
- **近优随机**：在近优动作中随机选择，保留可复现随机种子。
- **探索型随机**：随机探索候选动作，并容忍短期回撤，增加路线差异。

逐关终局和目标条件来自 Core 引擎；关卡 MonoBehaviour 机制与 ScriptableObject 事件通过工具里的纯 C# 适配实现。建议把失败次数高的关卡作为下一轮人工试玩重点。
