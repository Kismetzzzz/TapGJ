## 资源与合成

`Assets/Resources/ImportedEffects.asset` 绑定选中、爆点、范围三个预制体；`CardDissolve.asset` 绑定两种消散、泛光配置和合成材质。运行时只实例化粒子子节点，保留粒子曲线、贴图与共享材质，关闭爆点组的循环控制。演示相机、录制轨道和预览脚本不参与播放。

`ImportedParticleEffect` 将粒子渲染到独立纹理，通过界面或世界空间平面显示。范围模型只有侧壁，因此使用倾斜观察角度呈现边缘；把相机纹理四角反投影到素材地面后，按模型实际边长建立显示网格，避免观察角度让边界斜穿格线。棋盘平面随后通过现有透视映射贴到背景上，范围合成强度为 35%。离屏舞台各占独立位置，泛光使用局部体积，销毁时释放相机、材质、纹理和自建网格。

选中材质引用的原主贴图缺失，会回退为整块白色；原界面输出还重复叠加父节点中心偏移，让光效偏到右下。运行时为选中粒子单独复制材质，绑定按卡牌比例生成的透明边框遮罩，清除原图集缩放和滚动，并使用加法颜色叠加。输出锚定父节点中心后局部偏移归零，适配左上角轴心的卡面。卡面内部保持透明，不再产生覆盖卡面的矩形色带。共享素材保持原样；取消选中后释放边框遮罩和材质副本。

## 复合元素尺寸

复合元素图案按实际投影后的单格四边形确定尺寸，取以格心为中心、能够完整放入四边内的最大正向方形，再留出 2% 的边距。这样尽量用满格子高度，同时不再跨到上下相邻格。弹出动画超出基准缩放时也限制最终图案边界；缩小和淡出继续跟随原动画。图片保持原比例和格心，普通棋子尺寸、点击区域与作用范围沿用原逻辑。

`Assets/UI/BoardEffectComposite.mat` 为棋盘使用预乘透明度合成，保留透明像素中的加法发光。普通 UI 的透明度混合会丢失这部分颜色。`CardEffectComposite.shader` 的卡牌模式继续从独立透明度纹理还原卡面遮挡量，棋盘模式使用渲染纹理自身的透明度。

## 验证入口

`ImportedEffectPlayModeTests` 检查五组资源映射、实际粒子渲染、最终界面中的颜色差异、重复同步、取消、分解、关闭和重开清理，以及两种消散资源。`BattleGameplayPlayModeTests` 检查 64 格中心、实际渲染网格、背景读图标记和格缝点击。卡牌消散的既有运行测试与固定时间画面对照继续使用。

尺寸检查覆盖五种复合元素、近远两端整排棋格、棋盘左右边缘、格心、点击和动画缩放；使用图案四角反算所在逻辑格，防止仅检查宽度而漏掉跨格。画面预览将普通元素与复合元素放在相邻两排，用于检查遮挡。

单格尺寸修正时的运行检查 37/37 全部通过，结果保存为 `Artifacts/BoardEffects/playmode-single-cell.xml`。新增检查在修正前能复现跨格问题。已核对 1920×1080、1280×720 的实际渲染，预览为同目录的 `gameplay-single-cell-1920x1080.png`、`gameplay-single-cell-1280x720.png` 和 `composites-single-cell-detail.png`。

选中光效修正后的回归检查 39/39 全部通过，结果保存为 `Artifacts/BoardEffects/selection-final.xml`，覆盖选中、普通与火焰消散、融合爆点、范围光效和棋盘交互。新增画面对照在修正前能复现不透明矩形；修正后检查 1080p、720p 各三个播放时刻的中心透明、卡面内部原色及实际边光，并验证同心和取消后的资源释放。预览为 `selection-fixed-1920x1080.png`、`selection-fixed-1280x720.png` 和 `selection-fixed-detail.png`。
