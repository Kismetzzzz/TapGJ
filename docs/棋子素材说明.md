# 棋子素材

`Game` 场景的 `BoardAnchor` 通过 `Piece Art` 引用 `Assets/UI/Data/BattlePieceArt.asset`。
配置同时供棋盘原始显示和对局界面的棋子显示使用；素材放在 `Assets/UI/Art/AnimalPieces/`。

| 棋子 | 配方 | 素材 |
| --- | --- | --- |
| 金 | — | Metal.png |
| 木 | — | Wood.png |
| 水 | — | Water.png |
| 火 | — | Fire.png |
| 土 | — | Earth.png |
| 烬 | 木＋火 | Ember.png |
| 熔岩 | 火＋土 | Lava.png |
| 矿晶 | 土＋金 | Ore.png |
| 寒钢 | 金＋水 | ColdSteel.png |
| 灵泉 | 水＋木 | SpiritSpring.png |

十张图片由提供的透明 PNG 裁去留白和零散噪点，再等比放入 512 × 512 透明画布；保留角色和复合图中的花瓣、晶石、火焰。图片以原色直立显示，相生时按新元素换图，生成与消散沿用现有动画。

后续替换时，将透明图片导入为单张 Sprite，整张画布的 Pixels Per Unit 与像素边长相同，然后拖入配置的对应字段。对局界面使用等比缩放，图片不拦截格子点击。对应字段留空时继续显示原有元素字和色块，复合元素还会显示光环。

本次仅接入棋子；基础元素卡面继续由 `BattleCardArt.asset` 配置，当前没有新增复合元素牌种。

验证入口：`BattlePieceArtTests`、`BoardViewTests`、`BattleBoardViewportTests` 和 `BattleGameplayPlayModeTests`。实际画面预览输出到 `Artifacts/AnimalPieces/`。
