## 实际复用范围

运行时从原预制体实例化 bofang/kapai_01 与 bofang/lizi 两组 ParticleSystem。保留原包的粒子发射、寿命、运动、CustomData 溶解曲线、材质参数和 VFX/Pandavfx_v2.3 shader；主贴图替换成当前卡面，并转换纹理上下方向、适配显示尺寸。

作者的 Camera01、循环播放控制与预览 Timeline 不参与出牌播放。原预制体资源加载时仍可能报告 Recorder 轨道的缺脚本警告，不影响这两组粒子的运行。

Canvas Overlay 通过离屏相机和 RawImage 显示原效果。Assets/UI/Shaders/CardEffectComposite.shader 只负责透明度、UI 遮罩和画面合成，不计算溶解，也不生成粒子。原包火星使用加法混合，因此卡面遮挡量由没有后处理的另一台离屏相机单独渲染，火星与光晕只叠加颜色。

CardDissolve.asset 显式绑定包内 Camera Profile 1.asset 和 PPv2 资源，复用原配置的 Bloom（intensity=1、threshold=1），修补发生在接入配置，原预制体未改。颜色输出采用 ARGBHalf 与 HDR，保留溶解边缘和火星的高亮值。每张卡的后处理体积只包围自己的离屏相机；同时消散的卡牌与玩法相机互不影响。houqi.mat 属于作者预览画面的整屏处理，不参与卡牌合成。

## 触发与替换

- Game.unity：成功出牌（包括融合、分解）或弃牌后，HandView.Sync 检测被逻辑层移除的手牌并播放。失败操作不移除卡牌，因此不会误播；关闭动画或快进时仍即时移除。
- BattleUI.unity 预览：选牌后点击“弃牌”。正式玩法确认操作成功后调用 BattleUiController.ConsumeCard(槽位索引)。

原卡牌立即停止交互，原包粒子在原位置显示，按原卡面粒子的约 1.5 秒寿命播完后回收。副本独立于手牌重排；暂停时间缩放时也能播放和释放临时相机、材质及渲染纹理。

默认保留原包配色。CardDissolve.asset 的 tintByElement 开启后，只按五行替换溶解边缘与火星颜色，保持曲线和运动。各卡牌使用独立材质实例，不改写原包共享材质；同种效果换颜色、主贴图无需分别制作资源包。
